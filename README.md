# PCパーツ底値ウォッチ

https://fontom-ai.github.io/pc-price-watch/

グラボ・CPU・メモリ・SSDなど自作PCパーツの新品最安値を、楽天市場とYahoo!ショッピングの公式APIから2時間ごとに集計し、日ごとの最安値の推移を公開しているサイトです。このリポジトリは自動生成された公開用ページの置き場です。

- 品目ごとの最安値と価格推移（例：[RTX 5070](https://fontom-ai.github.io/pc-price-watch/p/rtx5070.html)）
- [SSD・メモリの容量単価ランキング](https://fontom-ai.github.io/pc-price-watch/ranking.html)
- [構成シミュレーター](https://fontom-ai.github.io/pc-price-watch/simulator.html) / [自作 vs BTO](https://fontom-ai.github.io/pc-price-watch/bto.html)
- [価格データ（CSV・CC BY 4.0）](https://fontom-ai.github.io/pc-price-watch/data.html)

サイトはアフィリエイト広告を利用しています。

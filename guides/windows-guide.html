自作PCのWindows：入手方法・ライセンスの種類・インストールの流れ

公開日 2026-10-02 ・ 最終更新 2026-10-02

自作PCにWindowsを入れる方法を、ライセンスの種類（パッケージ版・DSP版）、Windows 11の動作要件、インストールメディアの作り方まで整理しました。

【PR】本ページはアフィリエイト広告を利用しています

自作PCには、基本的にWindowsは付属しません。OSは別に用意する必要があります。ここでは、入手の方法と、インストールの流れを整理します。ライセンスの条件は変わることがあるため、購入前に必ずMicrosoftや販売店の最新の案内を確認してください。

1. Windows 11の動作要件

自作PCで使うパーツが、次の主な要件を満たしている必要があります（Microsoftの公式要件の一部です）。

  • 64ビット対応のCPU（対応するプロセッサの一覧がMicrosoftから公開されています）
  • メモリ4GB以上、ストレージ64GB以上
  • UEFI（セキュアブート対応）とTPM 2.0

最近のマザーボードは、多くがTPM（機能名は「fTPM」「PTT」など）に対応しており、BIOSで有効にする設定が必要な場合があります。

2. ライセンスの種類

種類 特徴
パッケージ版（リテール版） 単体で購入できる。PCを買い替えたときに、条件を満たせば別のPCで使える場合がある
DSP版 特定のパーツ（SSDやメモリなど）と同時に購入する形で販売される。販売店や時期で条件が異なる
ダウンロード版 Microsoftや販売店からダウンロードして購入する
OEM版（メーカー製PCに付属） 基本的にそのPCに結びついており、別のPCには移せない

どれを買うかは、予算と、将来PCを組み替える可能性があるかで決まります。ライセンスの移行や認証の条件は、必ずMicrosoftの案内で確認してください。

3. HomeとProの違い

  • Home：一般的な家庭向け。
  • Pro：BitLocker（ドライブの暗号化）や、リモートデスクトップで接続を受ける機能などが加わります。

業務で使う、データを暗号化したいなどの理由がなければ、Homeで足りる人が多くいます。

4. インストールメディアを作る

Microsoftの公式サイトから、メディア作成ツールをダウンロードして、USBメモリにインストール用のメディアを作れます。別のPCで作業し、容量8GB以上のUSBメモリを用意します。

  1. 別のPCでMicrosoftの公式ページからツールを入手して、USBメモリにメディアを作成
  2. 組み立てたPCにUSBメモリを挿して起動（BIOSの起動順を、USBメモリに設定）
  3. 画面の案内に従って、インストール先のSSDを選んでインストール
  4. インストール後に、ライセンスの認証（プロダクトキーまたはデジタルライセンス）

5. インストール先の注意

  • システム用SSDとデータ用SSDを分けると、OSを入れ直してもデータを守りやすくなります（SSDの選び方）。
  • インストール時は、データ用のSSDをいったん外しておくと、間違えて消すことを防げます。

6. インストール後にやること

  1. Windows Updateを実行
  2. マザーボードやグラボのドライバーを、メーカーの公式サイトから入手して更新
  3. BIOSのメモリ設定（XMP・EXPO）を確認（メモリの選び方）
  4. バックアップの設定

組み立てから初回起動までの流れは組み立て手順で解説しています。古いPCから移行する場合はデータ移行と古いPCの処分もどうぞ。
